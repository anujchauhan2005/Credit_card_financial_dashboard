# Credit Card Financial Dashboard 📊

A complete end-to-end Credit Card Financial Dashboard project built using **Power BI**, **SQL**, and **Excel** to analyze customer spending behavior, transaction trends, and revenue insights.

---

## 🚀 Project Overview

This project focuses on building an interactive financial dashboard for credit card operations. The dashboard provides real-time business insights into:

- Revenue trends
- Customer demographics
- Transaction analysis
- Card category performance
- State-wise revenue contribution
- Interest earned
- Activation & delinquency rates

The project demonstrates the full workflow from raw CSV files to interactive Power BI dashboards.

---

## 🛠️ Tech Stack

- **Power BI**
- **MySQL / SQL**
- **Excel**
- **DAX**
- **Data Visualization**

---

## 📂 Project Workflow

1. Data preparation using Excel
2. Database creation in SQL
3. Importing CSV files into SQL database
4. Connecting SQL database with Power BI
5. Data cleaning and transformation
6. Creating DAX measures
7. Building interactive dashboards
8. Generating business insights

## 📊 Dashboards Included

### 1️⃣ Credit Card Transaction Dashboard
Provides insights into:

### 2️⃣ Credit Card Customer Dashboard
Provides insights into:

- Gender-based revenue

- Education level analysis
- Customer acquisition trends

---

## 📈 Key Insights

### Week-on-Week Analysis
- Revenue growth increased significantly
- Transaction amount and count showed positive growth
- Customer acquisition improved steadily

### Overall Business Insights
- Blue and Silver credit cards contribute the majority of transactions
- Male customers generate higher revenue contribution
- Top-performing states contribute a major share of total revenue
- Activation rate and delinquency rate help evaluate customer behavior
